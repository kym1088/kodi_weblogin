* KODI용 밤보리 ott 애드온 로그인 지원파일
  (각 ott 보안강화에 따른 대응)

* 사용방법
1. 필요한 ott별 파일 다운로드 (.exe)
    - 티빙 : tvingWebLogin.exe
    - 디즈니 : disneyWebLogin.exe
    - 쿠팡 : coupangWebLogin.exe

2. 로그인 쿠키 파일 생성 (ott별로 세부적인 부분은 틀리지만, 결론은 프로필 선택까지 진행하여 초기화면까지 진입)
   - pc에서 exe파일 실행
   - 크롬 브라우저(시크릿 모드 또는 디버깅 모드) 실행되고 로그인 페이지 열림
   - 사람이 직접 로그인 하듯이 id 유형 선택
   - 아이디, 비번 입력하고 프로필 선택화면 나오면 프로필까지 선택
       ( 자동로그인 체크는 해제 )
   - ott 메인화면으로 전환되면서 크롬 브라우저가 자동 종료됨
   - 실행파일 폴더에 암호화된 로그인정보파일 생성되면 1단계 종료
     - 티빙 : tvinginfo-시간.twc
     - 디즈니 : disneyinfo-시간.twc
     - 쿠팡 : coupanginfo-시간.twc

3. 로그인정보 암호화 파일 kodi 장비에 복사

4. kodi 애드온 실행후 로그인정보 암호화 파일 선택(업로드 작업)
